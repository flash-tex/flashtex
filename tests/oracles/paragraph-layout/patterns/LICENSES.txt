Hyphenation pattern files vendored in this directory
=====================================================

Both files are copied byte-for-byte from TeX Live 2026 and are NOT modified.
They are data read by src/liang.rs (include_str!); no TeX program is used.

hyphen.tex
----------
Source:    texmf-dist/tex/generic/hyphen/hyphen.tex (TeX Live 2026)
What:      The Plain TeX hyphenation tables by Donald E. Knuth (4447 patterns,
           14 \hyphenation exceptions). TeX Live's language.dat loads this file
           for the `english` language, pdflatex's default.
Licence (verbatim from the file header):

    % Unlimited copying and redistribution of this file are permitted as long
    % as this file is not modified. Modifications are permitted, but only if
    % the resulting file is not named hyphen.tex.
