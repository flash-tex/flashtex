# Brand assets

The FlashTeX brand kit. [BRAND.md](BRAND.md) is the guide (colours,
typography, don'ts); the SVGs here are the single source for every logo and
icon in the repository.

Derived files are generated by [`generate.py`](generate.py) and committed, so
builds need no rasteriser. After changing an SVG, run:

```sh
python3 assets/brand/generate.py   # needs rsvg-convert (brew install librsvg) and iconutil
```

| Output | Used by |
|---|---|
| `png/flashtex-social.png` (1280x640) | GitHub social preview (upload in repo Settings) |
| `site/brand/*.svg`, `site/favicon*`, `site/apple-touch-icon.png`, `site/og.png` | website |
| `apps/mac/Resources/AppIcon.icns` | Mac app (`make-app.sh`, `CFBundleIconFile`) |
| `apps/ios/FlashTeXPad/Assets.xcassets/AppIcon.appiconset` | FlashTeXPad (light + dark) |
