# Divergence probes: one construct per document

Owner: lane `linux-unknown-unknowns` (Claude Code, machine `linux-primary`).
Created 2026-09-14. Each directory is a **minimal reproducer** for one place
where `flashtex-render --v2` → `flashtex-pdf-exact from-v2` differs from
pdfLaTeX, cut down from the realistic documents in
[`fixtures/real-world/`](../real-world/README.md) until one construct is left.

These are **not** part of the default corpus run. `tools/real-world-corpus/run.py`
and `tools/visual-oracle/rank.py` both default to `fixtures/real-world`; point
them here explicitly:

```sh
export FLASHTEX_FONT_DIRS=apps/mac/Fonts
export FLASHTEX_TFM_DIRS=apps/mac/Fonts/texmf/fonts/tfm/public/lm:apps/mac/Fonts/texmf/fonts/tfm/jknappen/ec:apps/mac/Fonts/texmf/fonts/tfm/public/amsfonts/symbols
python3 tools/visual-oracle/rank.py --fixtures fixtures/divergence-probes \
  --render crates/render-pipeline/target/release/flashtex-render \
  --pdf-exact crates/pdf/target/release/flashtex-pdf-exact \
  --texbin "$(dirname "$(command -v pdflatex)")" --thumbs 0 --only min-abstract
```

Every `reference.pdf` here was generated by that harness with **TeX Live 2025**
(`pdfTeX 3.141592653-2.6-1.40.27 (TeX Live 2025/nixos.org)`,
`SOURCE_DATE_EPOCH=0 FORCE_SOURCE_DATE=1`, two passes); each `reference.json`
records the SHA-256, page count, argv and `"reference_engine": "TeX Live 2025"`.
The MacTeX-generated references under `fixtures/real-world/` are a different
engine build and were not touched. pdflatex is an oracle only and never runs in
the product path.

## What each probe isolates

`Δ` is the word-origin delta of the *body text around* the construct
(candidate − reference, bp), which is what makes a divergence visible to a
reader. `words` is reference/candidate word counts — a shortfall on the
candidate side means ink the reader will not see. Math words often fail to
align for a benign reason (the reference splits math into per-glyph runs), so
only the surrounding prose deltas and the explicit "nothing drawn" diagnostics
are treated as evidence here.

| probe | construct | measured |
|---|---|---|
| `min-abstract` | `abstract` in `article` | body below is **24.58 bp** too high; abstract body set in `LMRoman10-Regular` at the full measure where pdfLaTeX uses `SFRM0900` indented to x 96.907 |
| `min-paragraph` | `\paragraph{...}` run-in heading | heading not bold (`LMRoman10-Regular` vs `SFBX1000`), indented by `\parindent` (dx **+14.94 bp**) instead of flush, and **13.94 bp** of space above it missing per occurrence |
| `min-float-table` | `tabular` inside a `table` float | the 9 tabular words are **not drawn at all**; body below rises **38.06 bp** |
| `min-footnote-float` | `\footnote` in a document that also has a float | both footnotes **dropped** (ref 51 words, cand 33) |
| `min-natbib`, `min-newblock` | `natbib` `\citet`/`\citep`, `\newblock` | `\citet`/`\citep` unsupported: 29 reflowed words, median dx **+60.58 bp**. `\newblock` alone recovers cleanly (max Δ 0.03 bp) — noisy, not a layout bug |
| `min-hrulefill` | `\hrulefill` | the rule is not set: `Date:` lands **198.51 bp** left of pdfLaTeX |
| `min2-headings`, `min3-subsubsection` | `\subsubsection` | the `1.1.1` number is **missing**; heading text starts **35.00 bp** too far left |
| `min-description` | `description` list | list body not indented by `\leftmargin`: dx **−24.91 bp**; list **11.96 bp** short |
| `min-bigdelim-12pt` | `\bigl`/`\Bigl`/`\biggl`/`\Biggl` at 12 pt, no amsmath | display **11.96 bp too tall** over two displays (≈5.98 bp each); the same probe at 10 pt (`min2-fence-*`) is exact |
| `min-tall-parens`, `min-huge-fences`, `min2-cases`, `min-sqrt-tall`, `min-norms` | cmex10 extensible pieces | `cmex10 code 0x3a–0x41, 0x75/0x76 has no Latin Modern Math glyph mapping; nothing drawn for it` — grown `(`, `)`, `{`, `}`, `√` and `cases` braces **paint nothing**. `min-norms` renders `\left\|` as a run of four bars |
| `min-langle` | `\langle` / `\rangle` | `no math glyph for '〈'; empty box used` |
| `min2-pagestyle` | `\pagestyle{empty}` in the preamble | rejected: `\pagestyle is not supported in the document preamble` |
| `min2-preamble-switches` | `\small`/`\bfseries` inside a `\newcommand`, `\renewcommand{\baselinestretch}` | `LaTeX Error: Command \baselinestretch undefined`; median dx **−18.47 bp**, 5 reflowed words |
| `min3-baselinestretch` | `\renewcommand{\baselinestretch}{1.5}` | leading not stretched: max dy **11.96 bp** |
| `min2-itemize` | two lists separated by a blank line | second list's items **9.96 bp** low |
| `min3-verse-flushright` | `flushright` / `flushleft` | **9.96 bp** vertical offset |
| `min2-nested-lists` | nested `enumerate` | **7.97 bp** vertical offset on the second outer item |

## Probes that show no divergence (keep them: they are the regression floor)

`min-maketitle`, `min-chapter`, `min-toc`, `min-twocolumn`, `min-tabular`,
`min-quote`, `min-curly-quote`, `min-footnote` (no floats), `min3-itemize-only`,
`min3-enumerate-only`, `min3-itemize-multipar`, `min4-itemize-wrap`,
`min3-centering`, `min3-setlength`, `min2-bigsum`, `min2-fence-plain`,
`min2-fence-onefrac`, `min2-fence-nested`, `min2-nested-dfrac-bare`,
`min2-pmatrix-3row` — every aligned word within **0.01 bp** of pdfLaTeX.
`min-twocolumn` aligns all 439 words at ≤0.01 bp.

## Honest limits

- No rasterizer exists on `linux-primary` (`pdftoppm`, `gs`, `pdftotext`,
  `qpdf` and `mutool` are all absent), so these numbers are **word geometry
  only** — `tools/visual-oracle/pdftext.py` replaying the reference content
  stream against the rendering-v2 display list. No pixel comparison was run.
- The bundled `apps/mac/Fonts/texmf/fonts/tfm/jknappen/ec` has no `ectt*.tfm`,
  so any probe containing `\texttt`/`verbatim` is measured on **substituted**
  metrics. Those were deliberately removed from these probes; the harness
  reports `ec_metrics_unavailable` as a FONT-ENV FAILURE when one slips in.
- Word alignment is by text. Math rarely aligns word-for-word, so a
  reference/candidate word-count gap inside a display is only evidence when a
  producer diagnostic says something was not drawn.
