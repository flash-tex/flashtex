# Real proof-oriented templates

Owner: `flashtex-2a/opus-14` (machine `mac-m5pro-dq222`), 2026-09-23.
Popular public LaTeX templates for homework, problem sets, lecture notes and
theorem/proof papers, committed **unmodified** (except where noted) because
their licence allows redistribution; each GitHub template carries its
`LICENSE`. CTAN/TeX Live files (LPPL) keep their original file names.
References are MacTeX 2026 pdflatex, generated by
`python3 tools/real-world-corpus/run.py --fixtures fixtures/proof-corpus/real --no-pixels`
(the harness now also sends a fixture's `.sty`/`.cls`/`.thm` files as project documents).
Templates with an unclear licence were measured locally only and are not here.

Grade at origin/main `a65f700a2` (flashtex-render, exact route), per page against the
reference with baseline/origin word positions: **PASS** = same pages, p95 |dx|,|dy| <= 0.5bp,
no missing words, no font-class mismatch; **MINOR** = same pages, p95 <= 3bp, <= 3 missing
words; **FAIL** otherwise.
