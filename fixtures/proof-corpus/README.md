# Proof-document corpus

Owner: `flashtex-2a/opus-14` (machine `mac-m5pro-dq222`), 2026-09-23.
Synthetic documents written for this corpus: math homework, lecture notes,
problem sets and short papers built around theorem / lemma / definition /
proof. Same layout and harness as [`fixtures/real-world/`](../real-world/README.md):
each directory has `main.tex`, a MacTeX 2026 pdflatex `reference.pdf`
(`SOURCE_DATE_EPOCH=0 FORCE_SOURCE_DATE=1`, repeated until stable) and its
`reference.json`, generated by

```sh
python3 tools/real-world-corpus/run.py --fixtures fixtures/proof-corpus --render <flashtex-render> --no-pixels
```

pdflatex is an oracle only. `crates/render-pipeline/tests/theorem_page_penalties.rs`
reads `paper-cref` and `linalg-theorem-lists` directly.

| fixture | what it exercises |
|---|---|
| `amsthm-styles` | `\theoremstyle{plain,definition,remark}`, shared counter and `[section]`, starred environments, optional notes, `\ref` to a proposition |
| `proof-qedhere` | `\begin{proof}[Proof of Lemma~\ref{..}]`, `\qedhere` at the end of `\[..\]`, `align*`, `enumerate`, `itemize` and a numbered `equation`; `\renewcommand{\qedsymbol}` to `$\blacksquare$` and `\textsc{qed}` |
| `nested-proofs` | a claim (`\newtheorem{claim}{Claim}[theorem]`) and its proof inside a proof; a proof inside an `enumerate` item; proofs inside `\item[(a)]` |
| `hw-problem-solution` | homework template: `\newtheorem{problem}`, `\newenvironment{solution}{\begin{proof}[Solution]}{\end{proof}}`, `enumitem` `[label=(\alph*)]`, `\qedhere` in a list, `\maketitle` |
| `lecture-notes-groups` | lecture notes: `T1` + `lmodern`, `[section]` numbering with shared counters, `\DeclareMathOperator`, corollaries with notes |
| `problem-set-solution-env` | problem set: `mathtools` `\DeclarePairedDelimiter` (`\abs`, `\norm`, `\abs[\big]`), `\coloneqq`, `cases`, `\newenvironment{solution}` without amsthm, definition-style exercises |
| `paper-cref` | short paper: `abstract`, `hyperref` + `cleveref` `\cref` of theorems sharing a counter, `\numberwithin{equation}{section}`, `\eqref`, `\begin{proof}[Proof of \cref{..}]` |
| `analysis-proofs` | 12pt epsilon-delta proofs: `align*` with `\qedhere`, `\left\{..\right\}`, inline `cases` in a theorem statement |
| `linalg-theorem-lists` | `enumerate[label=(\roman*)]` inside a theorem, `description` with `\qedhere` inside a proof, `pmatrix` displays in a proposition and a proof, a two-page break between theorems |
| `induction-numbering` | `\newtheorem{theorem}{Theorem}[subsection]`, `\newtheorem*{mainthm}`, `definition[section]`, numbered `align` with `\notag` and `\qedhere`, `\binom`, strong induction |
