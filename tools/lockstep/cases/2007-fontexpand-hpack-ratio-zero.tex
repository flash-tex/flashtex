% #1220: with \pdfadjustspacing, post_line_break packs each line with
% hpack(..., cal_expand_ratio). When the line is short (or long) by a few
% sp, the expansion ratio rounds to 0 and hpack returns before it sets
% glue_order, glue_sign and glue_set (pdftex.web "Determine horizontal glue
% stretch setting"): the line's box shows what the node that last used those
% words left there. That agrees with pdfTeX only when nodes land where
% pdfTeX puts them (SyncTeX's node sizes, and the file tag and line get_node
% writes; changes/synctex.ch) and a word written as |lh| reads back as
% |b0|/|b1| as in C (texmfmem.h; changes/web2c.ch).

\f \pdfadjustspacing=2
