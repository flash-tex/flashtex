Every float in this document carries body material that is not a
picture. The paragraph around it is here so the float has text to displace and
so the page builder has a column to break, and it runs to several lines so that
a change in the height of the float moves something measurable.

argument, which gives the oracle a baseline below the float to compare against
as well as one above it.
