## 5. Red-team of the changed sections

1. **§12 P5's verdict must wait for a board that actually ran #1915's code.** #1915 was
   tested offline, by rebuilding the board from 41306949575's artifacts (REPORTED). Under
   R13 a gate is met only on main, measured by CI. **Decision:** P5 stays "pending board
   run" until a scheduled or dispatched board on a SHA at or after `f53095ff2` is all green.
2. **The T3 v1 baseline is frozen evidence, and that is safe only while the oracle is
   unchanged.** The file records the oracle's tlpdb (`909745461c89`) and labels a mismatch
   CROSS-ORACLE. When LaTeX 2026-11-01 or a TeX Live update re-pins the oracle, the old
   column becomes cross-oracle on every T3 row. **Proposal (refinement):** the upgrade lane
   must decide, before it re-pins, whether a CROSS-ORACLE old cell still counts as green.
3. **S₁ adds a persisted state with a new soundness surface,** and its own test is red on
   main. §5.3's rule is a soundness case per rule. S₁'s fill-from-S₀ pass relies on
   convergence, and the sweeps are where an unsound S₁ restore would show up. **Proposal:**
   #1919 or a follow-up fixes the macOS failure, and S₁ joins the nightly sweeps
   (`FLASHTEX_S1` on/off), as BOX-MEMO did, before the next T7 reference run counts it.
4. **No T7 reference run since the hot-path changes.** Eight PRs today changed restart,
   restore and convergence (§12 P4). P4 was met on 10-21's code. **Recommendation:** one
   `scripts/t7-reference.sh` run on the Q1 Mac once main is green, so §1.2 is re-measured
   on today's code.
5. **`crates/document-runtime` has no consumer** (VERIFIED: 0 workspace dependents, 0
   references in `apps/`, `scripts/` or `.github/`; 5,546 Rust LOC). It was the old
   compiler's stdio session manager. The retirement plan kept it as an IDE crate, but its
   only producer is gone. **Proposal:** delete it in a small lane under the §4.6 reference
   check and a revert check. `collaboration-core` stays, by ruling 1. `font-discovery` stays,
   because the Unicode mode links it (S7).
6. **The merge-fast trade has a cost today.** Main's macOS legs were red for most of the
   day, and the 2-hour fix-forward rule (§9) did not keep main green. §11 now records this
   (the CI-protection row). No change to §9 is proposed from one day of data. The Commander
   should watch the rate: if post-merge red persists for a week, a macOS smoke job in the
   gate is a candidate change.
7. **Header drift.** The DESIGN.md header still showed P4 "in progress" and the 10-05 CI
   picture as current. **Fixed:** the header now says P4 met (10-21) and P5 pending, and the
   10-05 block is labelled as a record.
