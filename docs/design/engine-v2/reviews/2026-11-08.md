2. **The required `engine parity` gate has not failed on a failing engine test since
   2026-10-05** (REPORTED, #2085, still open; BELIEF that the mechanism is right, since the
   code path is described exactly).

   - Since sharding (30158e6ab, 2026-10-05), `step_tests` has ended in a doc-test `if`, so
     `cargo test`'s status is dropped on every shard.

   - So, for 34 days, an engine-test failure has been able to pass the queue. P-T1/P-T2,
     lockstep, trip and etrip are separate steps and are not affected (BELIEF; not
     re-checked).

   This is the highest-severity finding of this review.
3. **P3's post-merge gate is red on main** (VERIFIED, run 41510925218). #2081 added 10
   preview probes to the zero-tolerance sweep, and 31 renders of three of them differ. The PR
   says auto-merge would go on "only after that sweep is green". It merged on 11-02 19:31Z,
   and the sweep fails on main. All 88 parity fixtures still pass, so P3's own evidence holds.
   The probes found real differences, which is their purpose. They have not been fixed or
   marked INCOMPLETE.
4. **LaTeX 2026-11-01 has shipped** (VERIFIED, [latex-project.org/news](https://www.latex-project.org/news/):
   "LaTeX 2026-11-01 release with many updates", 1 November 2026). The §7 pre-release dry run

   who runs `tlmgr update` gets a kernel that no gate has run.
5. **The design itself holds.** Nothing landed in the window reverses a D-decision. The
